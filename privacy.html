隱私權說明

最後更新：2026 年 11 月 3 日

我們存哪些資料

  • Google 帳號的基本資料：名字、大頭貼、電子郵件，用來登入和顯示你是誰。我們拿不到你的 Google 密碼。
  • 你記下的內容：支出、收入、預算、類別、優惠券、備註、照片（含你填的地點）、生日名單、記事本（行程、筆記、圖片）、背景圖片和設定。
  • 家庭資料：家的名字、成員和稱呼、頭像（你上傳的照片或選的笑臉顏色）、還沒加入的家人格子、邀請連結、全家的帳、存錢目標。
  • 這台裝置：為了下次打開能直接點自己的頭像登入，瀏覽器會記住你的稱呼和頭像；在「選擇使用者 → 編輯」可以從這台裝置移除。
  • 意見回饋：你在「意見回饋」送出的文字和評分。

誰看得到

  • 你的帳只有你自己看得到。你在「分享給家人」選擇分享多少，家人就只看得到那一層（只看總額、類別合計，或完整明細）。
  • 全家的帳只有加入這個家的成員看得到、改得到。
  • 照片和記事本只存在你自己的資料裡，不會分享給家人。
  • 我們不會把你的資料賣給或提供給第三方，也沒有廣告追蹤。

資料存在哪裡

資料存在 Google 的 Firebase（Cloud Firestore）雲端資料庫，傳輸時有加密。存取權限由資料庫的安全規則控管，規則公開在 GitHub 上。

照片的位置資訊

附照片時，如果照片裡有拍攝地點，網頁會在你的手機上讀出來，自動填進「地點」欄。上傳的照片會先壓縮，原始檔裡的其他資訊不會上傳。

怎麼刪除資料

登入後到「設定 → 帳號 → 刪除我的帳號和資料」，會刪除你的帳、照片、記事本、生日名單和設定，並離開所有家庭。想留著資料的話，先到「設定 → 匯出與備份」下載備份檔。

聯絡我們

有任何問題，請到 GitHub 留言，或在網站的「設定 → 意見回饋」告訴我們。
